# Project Rules

- Stack: Node.js, Express, TypeScript, Sequelize (SQLite dialect).
- Architecture: SOLID principles using Controller-Service-Repository pattern.
- Models: Use strict TypeScript typing for Sequelize models.
- Core Feature: Tasks can have nested subtasks (recursive self-referencing relationship).
- Testing: Jest for unit testing business logic (Services).
- Code Style: Modular, clean code, strict error handling.
